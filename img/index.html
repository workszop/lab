💡 What is Metadata?

Metadata is "data about data" — information stored alongside your image like file name, size, and format. The computer uses this to know how to read the file!

💡 How Resizing Works

When you shrink an image, the computer must decide which pixels to keep. This is called downsampling. Making images smaller reduces file size but loses detail!

💡 What is Binary Data?

Computers store everything as numbers. Each byte (8 bits) can hold a value from 0-255. Here we show bytes in hexadecimal (base-16) because it's more compact: FF = 255, 00 = 0. The first bytes often contain the file's "magic number" — a signature that identifies the file type!

💡 How Pixels Store Color

Each pixel uses 3 numbers (0-255) for Red, Green, and Blue. Mixing these creates all colors! R:255 G:0 B:0 = pure red. R:255 G:255 B:255 = white. That's 256 × 256 × 256 = 16.7 million possible colors!

🔍 What you see above: The entire image downsampled to a tiny grid. Lower resolution = fewer pixels = you can see each one! This is exactly how computer vision models "see" images.
